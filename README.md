# Proyecto Final Fundamentos Web - Taller de repuestos

## Descripción
Sistema de gestión de inventario para un taller de vehículos, permitiendo el registro, búsqueda y visualización de repuestos automotrices.

## Estructura del Proyecto
```
Proyecto_Final_Fundamentos/
├── css/
│   └── styles.css          # Estilos globales
├── js/
│   ├── buscar.js          # Lógica de búsqueda
│   ├── data.js            # Gestión de datos
│   ├── productos.js       # Visualización de productos
│   └── registro.js        # Lógica de registro
├── html/
│   ├── index.html         # Página principal
│   ├── buscar.html        # Página de búsqueda
│   ├── registro.html      # Formulario de registro
│   └── indicaciones.html  # Guía de uso
├── assets/
│   └── img/              # Imágenes de productos
├── package.json          # Configuración del proyecto
└── README.md            # Documentación
```

## Características Principales
- Registro de nuevos productos con validación
- Búsqueda avanzada con múltiples filtros
- Visualización paginada de productos
- Interfaz responsiva y amigable
- Almacenamiento local de datos

## Requisitos Técnicos
- Navegador web moderno con soporte para ES6+
- Soporte para LocalStorage
- Servidor web básico para desarrollo

## Instalación
1. Clonar el repositorio
```bash
git clone [URL del repositorio]
```
2. Navegar al directorio
```bash
cd Proyecto_Final_Fundamentos
```
3. Instalar dependencias
```bash
npm install
```
4. Iniciar servidor de desarrollo
```bash
npm start
```

## Uso
- Acceder a `index.html` para ver el catálogo de productos
- Usar `registro.html` para añadir nuevos productos
- Utilizar `buscar.html` para encontrar productos específicos
- Consultar `indicaciones.html` para guías de uso

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage para persistencia de datos
